# Wise Choice

Учебный сервис для проверки рекламы онлайн-курсов. Интерфейс, результаты и учебные материалы доступны на русском, казахском и английском.

## Запуск

Нужен Node.js 22.18 или новее.

```sh
npm ci
cp .env.example .env.local
```

Добавьте ключ Google AI Studio в `GEMINI_API_KEY` внутри `.env.local`. `GEMINI_MODEL` выбирает модель. Текущая модель по умолчанию: `gemini-3.6-flash`, с `thinkingLevel: low`. Ключ используется только сервером, `.env.local` исключён из Git.

```sh
npm run dev
```

Откройте адрес, который напечатает Next.js. Для production-сборки:

```sh
npm run build
npm start
```

## Как работает анализ

Сервер отправляет текст или скриншот в Gemini. Поддерживаются JPEG, PNG и WebP до 2 МБ. Отдельного OCR-сервиса не требуется: изображение читает Gemini. Ссылки не загружаются автоматически, нужно вставить текст или скриншот.

Gemini извлекает признаки и цитаты. `lib/analyzer.ts` рассчитывает показатели. Маркетинговое давление IMP отделено от риска: скидка или таймер сами по себе не доказывают мошенничество. Если сведений мало, вместо числовой оценки выводится соответствующее сообщение.

Спидометр показывает IDP: чем выше балл, тем меньше признаков риска. Коэффициенты исходной модели сохранены. В версии `author-v2.2` исправлен переход между ветками IDP: добавление учебных сведений больше не ухудшает оценку. Явные опасные обещания имеют приоритет над учебными сведениями в IDP, R и доверии. Gemini выделяет категории с подтверждающими цитатами. Скидка учитывается в IMP, но сама по себе не считается признаком мошенничества.

В исходном проекте маршрут API и `lib/analyzer.ts` использовали разные формулы IDP. Сейчас расчёт выполняется только через `lib/analyzer.ts`. Байесовское доверие в этой версии является эвристическим баллом исходной модели, а не проверенной статистической вероятностью. График показывает исходную точку 50 и рассчитанное значение; промежуточные наблюдения не выдумываются.

Полный CVF не рассчитывается без P и A. Интерфейс показывает предварительный вариант с P=0 и A=0 и помечает подстановки звёздочкой. Это сценарий без штрафа за цену и альтернативы, поэтому его результат выше полного CVF при положительных P и A. Исходные данные остаются `null`. Ценовой радар показывает извлечённую цену и позволяет добавить сопоставимые предложения вручную. Медиана относится только к выбранным курсам в той же валюте и не влияет на IDP.

IMP сохраняет авторскую формулу и ограничение 10 баллов. При большом числе приёмов он быстро достигает потолка и слабо различает их интенсивность. Это ограничение калибровки учебной модели. Новые правила применяются к новым проверкам; сохранённые результаты автоматически не пересчитываются.

Последние 10 результатов и выбранный язык сохраняются в localStorage. Скриншоты не сохраняются в истории. Цитаты остаются на языке исходной рекламы; названия, выводы и пояснения доступны на всех трёх языках.

## Проверки

```sh
npm test
npm run typecheck
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты ожидают локальный сервер на `http://127.0.0.1:3210`:

```sh
npm run dev -- --hostname 127.0.0.1 --port 3210
```

Для отдельного сквозного теста загрузки скриншота с реальным Gemini:

```sh
LIVE_GEMINI=1 npx playwright test tests/live.spec.ts
```

Этот тест расходует квоту подключённого API. Обычные тесты её не используют. Ошибка внешнего сервиса проверяется отдельным контролируемым ответом; успешные ответы Gemini не подменяются.

## Развёртывание

На Vercel задайте серверные переменные `GEMINI_API_KEY` и `GEMINI_MODEL`. В репозитории нет готового публичного деплоя этой версии.

### Проверка задержки моделей, 22 октября 2026

На двух одинаковых учебных объявлениях через текущий серверный обработчик Gemini 3.6 Flash вернула JSON за 2,8 и 2,6 секунды (повторный замер 2,8 и 5,5 секунды): IDP 88 для курса с программой и 14 для обещаний быстрого дохода, цены 45 000 и 99 000 KZT. Gemini 3.8 Flash в этом сравнении вернула ошибку сервиса и таймаут 80 секунд. Ранее один запрос со скриншотом на 3.8 прошёл примерно за 30 секунд. Это небольшой контрольный замер, а не оценка качества моделей на репрезентативной выборке. Для текущего приложения выбрана 3.6; автоматического переключения между моделями нет.

Сквозная проверка скриншота на 3.6 после переключения прошла за 10,6 секунды вместе с проверкой перевода и сохранения истории. Предыдущая попытка вернула ошибку сервиса, поэтому и для 3.6 нельзя обещать постоянную задержку или отсутствие временных сбоев.
